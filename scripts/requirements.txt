# --- Optional NVIDIA GPU acceleration (handbook/20) ---
# CPU is the default and works everywhere. The CUDA/cuDNN DLLs come from the
# nvidia-*-cu12 wheels pinned above; torch is not needed for the GPU path
# (2026-11-15). A dev venv may keep torch+cu126 for the research scripts, and
# core/device.py still falls back to its torch/lib if the wheels are absent.
# core/device.py detects the GPU with NVML (nvml.dll, part of the NVIDIA
# driver; no torch) and confirms onnxruntime's CUDA EP works before routing
# llama.cpp, OCR, person detection and the aligner to it (CPU fallback).
# RECALL_CUDA_DLL_PROVIDER=nvidia-wheels pins the DLL source for a check.
#
# onnxruntime-gpu is the default ORT build (OCR, HSEmotion). Pin to ≤1.26.x
# (CUDA 12) to match the CUDA 12.6 wheels — 1.27+ ships for CUDA 13.
# core/device.py preloads the CUDA/cuDNN DLLs from the wheels' bin folders by
# path via ort.preload_dlls() and probes the CUDA EP before advertising
# it. OCR tries GPU when the EP works and falls
# back to CPU on init failure. Force CPU OCR with RECALL_OCR_GPU=0.
# Safe non-device OCR speed-ups still live in engines/ocr/ocr.py:
#   - RECALL_OCR_MAX_SIDE (default 1280): downscale the OCR input frame
#   - ocrStride (default 3): OCR cadence in seconds.
# (AMD/Intel GPUs: onnxruntime-directml would be the cross-vendor route.)
