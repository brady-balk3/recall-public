# --- Optional NVIDIA GPU acceleration (handbook/20) ---
# CPU is the default and works everywhere. For an NVIDIA GPU, install the CUDA
# build of torch + torchvision (MUST match versions):
#   pip install torch==2.12.1+cu126 torchvision==0.27.1+cu126 --index-url https://download.pytorch.org/whl/cu126
# core/device.py auto-detects CUDA and routes the ASR to it (CPU fallback).
# Person detection runs on onnxruntime's providers, not torch -- see
# core/device.py get_ort_providers() and engines/vision/person_onnx.py.
#
# onnxruntime-gpu is the default ORT build (OCR, HSEmotion). Pin to ≤1.26.x
# (CUDA 12) to match torch+cu126 — 1.27+ ships for CUDA 13.
# core/device.py preloads torch's CUDA/cuDNN via ort.preload_dlls() and probes
# the CUDA EP before advertising it. OCR tries GPU when the EP works and falls
# back to CPU on init failure. Force CPU OCR with RECALL_OCR_GPU=0.
# Safe non-device OCR speed-ups still live in engines/ocr/ocr.py:
#   - RECALL_OCR_MAX_SIDE (default 1280): downscale the OCR input frame
#   - ocrStride (default 3): OCR cadence in seconds.
# (AMD/Intel GPUs: onnxruntime-directml would be the cross-vendor route.)
